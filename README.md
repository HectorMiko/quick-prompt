# quick-prompt

A macOS menu bar app that runs Claude prompts on the text you select.

## Install

Requires macOS 14 or later.

1. Download [quick-prompt.zip](https://github.com/HectorMiko/quick-prompt/releases/latest/download/quick-prompt.zip) and open it.
2. Drag **quick-prompt.app** into your **Applications** folder.
3. Open quick-prompt. macOS blocks it the first time because the app is not notarized:
   open **System Settings > Privacy & Security**, scroll down and click **Open Anyway** next to quick-prompt, then confirm.
4. When asked, allow quick-prompt in **System Settings > Privacy & Security** under **Accessibility** and **Input Monitoring**.
5. Click the quick-prompt icon in the menu bar, open **Settings… > Backend** and paste your Anthropic API key, or use your Claude subscription if Claude Code is installed.
